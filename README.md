# password-manager-cpp

Менеджер паролей, написанный в образовательных целях. Программа позволяет безопасно хранить пароли от различных сервисов в зашифрованной базе данных и управлять ими через UI-интерфейс.

## Возможности

*   **Полное управление записями:** Добавление, просмотр, поиск, обновление и удаление паролей.
*   **Надёжное шифрование:** База данных шифруется алгоритмом `AES-256` с использованием `SQLCipher`.
*   **Безопасный мастер-пароль:** Мастер-пароль не хранится на диске и проверяется только через попытку расшифровки БД.
*   **Защита памяти:** Пароль существует в оперативной памяти только во время ввода и немедленно затирается.
*   **Простота использования:** Интуитивно понятный консольный интерфейс.

## Установка и запуск

Самый простой способ начать работу — использовать готовые сборки из раздела **Releases**.

1.  Перейдите на страницу [Releases](https://github.com/aokigahara11/password-manager-cpp/releases) проекта на GitHub.
2.  Скачайте архив с последней версией.
3.  Распакуйте архив в удобную папку.
4.  Запустите исполняемый файл `password_manager.exe`.

## Использование

При первом запуске программа предложит создать **мастер-пароль**. Это единственный ключ ко всем вашим данным.

1.  Придумайте надёжный мастер-пароль и введите его.
2.  **Важно:** Пароль нигде не сохраняется. При его утере вы не сможете восстановить доступ к сохранённым паролям.
3.  После входа, откроется окно с главным меню, с основными действиями:
    *  Добавить новую запись (сервис, логин, пароль).
    *  Просмотреть существующуе записи.
    *  Сортировка.
    *  Поиск записи (обновление, удаление записи).
    *  Удаление всех записей.
