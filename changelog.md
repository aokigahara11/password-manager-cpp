# changelog

## [1.5.0] - 2026-07-01 - 10dcb91

### Добавлено
- Переход на графический интерфейс `ImGui`
- Поиск и фильтрация записей по сервису, email и паролю
- Обновление и удаление выбранной записи непосредственно из GUI
- Модуль `app` с разделением запуска (`main.cpp`) и рендеринга интерфейса (`src/app.cpp`, `src/ui/ui.cpp`)

### Изменено
- Удалён устаревший консольный UI и старые текстовые меню
- Улучшена обработка сохранения записей и работа с SQLite

### Удалено
- Консольный интерфейс и старые модули, связанные с устаревшим меню

    ## [1.4.0] - 2026-04-29 - 0975747

    ### Безопасность
    - Улучшена безопасность хранения мастер-пароля

    ### Добавлено
    - Проверка пароля теперь выполняется через попытку расшифровки базы данных `sqlcipher`
    - Пароль существует в оперативной памяти только на время проверки

    ### Изменено
    - Логика первого запуска перенесена в `main.cpp`
    - Изменена логика аутентификации: вход возможен только при успешной расшифровке БД

    ### Удалено
    - Удалены модули и классы `MasterKeyManager` и `FileManager`
    - Проверка пароля через тектовый файл и его хранение


## [1.3.2] - 2026-04-28 - b572e3f

### Добавлено
- Шифрование базы данных с использованием `sqlcipher`

### Проблемы
- `master_key.txt` хранится в открытом виде без какой-либо защиты

## [1.3.1] - 2026-04-06 - 29ce778

### Добавлено
- Новый метод `CheckLetter` для `Validator`, проверка наличия буквы для данных (service, mail, password)

## [1.3.0] - 2026-04-06 - c4856f2

### Добавлено 
- Новый класс `UI` для управления пользовательским интерфейсом
- Новый класс `InputReader` для валидации пользовательского ввода
- Новый класс `Validator` для проверки данных (service, mail, password)
- Циклы валидации для всех полей ввода
- Подтверждение копирования мастер-пароля в буфер обмена при первом запуске
- Предупреждение о слабости пароля (не блокирует сохранение)

### Изменено
- UI логика вынесена из `main.cpp` в отдельный класс
- Улучшена обработка пользовательского ввода


## [1.2.0] - 2026-04-04 - 6cef9f5

### Добавлено
- Переход на SQLite для постоянного хранения паролей
- База данных `passwords.db` для хранения записей
- Улучшенная обработка путей к файлам данных

### Изменено
- `PasswordManager` теперь использует SQLite вместо `std::vector`
- Пути к файлам master-key и базы данных исправлены для корректной работы

### Удалено
- Зависимость от in-memory хранения данных

## [1.1.0] - 2026-03-31 - dd6c1a3

### Добавлено
- Модуляризация кода: разделение на отдельные классы и файлы
- Классы: `PasswordManager`, `MasterKeyManager`, `FileManager`, `PasswordGenerator`, `ClipboardManager`
- Поддержка master-key для аутентификации
- Генерация случайных паролей
- Копирование в буфер обмена

### Изменено
- Рефакторинг монолитного кода на модульную архитектуру
- Улучшенная структура проекта с папками `src/`, `include/`

## [1.0.0] - 2026-03-31 - 660434d

### Добавлено
- Базовый менеджер паролей на C++
- Функции: добавление, просмотр, поиск, обновление, удаление записей
- Консольный интерфейс с меню
- Хранение паролей в памяти (std::vector)
